# Original website handoff templates

Four blank templates for recording service ownership, renewal responsibility, actual available access, delivery evidence and exit arrangements:

- Español: [plantilla-es.md](plantilla-es.md)
- English: [template-en.md](template-en.md)
- Français: [modele-fr.md](modele-fr.md)
- Català: [plantilla-ca.md](plantilla-ca.md)

Make a private copy per project and fill in references without secrets. These templates are not a contract, legal opinion, migration tool or proof that a provider supports delegated access or export. Record limitations instead of assuming a capability exists.

Do not include passwords, tokens, private keys or customer data. Do not send tests to third parties. Production restoration needs an agreed procedure. A backup file does not establish that restoration works; HTTP200 alone does not establish the correct page.

No accounts, production resources or purchases are created by these Markdown files. No application code executes. Native Hostbrid permissions and delivery are separate verification work.
